## 3. 最新硬件事实

### 3.1 CH_REPAIR / REPAIR_OUTPUT

用户已补充原理图事实：

```text
CH_REPAIR 的电流通路不经过 JK1 继电器。
REPAIR_OUTPUT 打开后，硬件自动控制修复电流到约 100mA。
CH_REPAIR 不需要打开继电器。
CH_REPAIR 不需要 set_Curr_Duty(SET_CURR(iREPAIR))。
```

当前已知源码现象：

```text
App/ch.c 中存在 REPAIR_OUTPUT = 1。
App/ch.c 中也存在 set_Curr_Duty(SET_CURR(iREPAIR))。
```

这部分必须修改。

### 3.2 DUMMY_LOAD

用户已补充硬件规则：

```text
DUMMY_LOAD 假负载默认关闭。
只在负载突然断开时打开。
打开后保持 5 秒。
5 秒到自动关闭。
```

当前已知源码现象：

```text
Bsp/gpio.h: DUMMY_LOAD = P00
Bsp/gpio.c: 初始化关闭 DUMMY_LOAD
App/ch.c: 仅看到 DUMMY_LOAD = 0
```

没有看到完整的“突然断开 -> 打开 5 秒 -> 自动关闭”逻辑。必须补齐。

## 4. 3.2 充电逻辑必须对齐

### 4.1 3.21 待机/插入检测

规格：

```text
接入市电、未插电池：红灯常亮，绿灯熄灭。
电池包插入：通过电压判断。
```

软件应满足：

```text
CH_IDLE：关闭充电输出，红灯常亮，绿灯灭。
通过电池端电压判断插入。
```

### 4.2 3.22 低于 1*N V

规格：

```text
电池包电压低于 1*N V：关断输出，红灯闪烁。
```

软件应满足：

```text
val.vout < vSTART：进入电压异常。
vSTART = 1.0V * N。
关闭输出。
红灯 1Hz 闪，绿灯灭。
电压/电流/通信类异常必须拔插电池后才重新检测。
```

### 4.3 3.23 1*N ~ 2.5*N V 低压充电

规格文字：

```text
电池电压在 1~2.5V 每节时，预充电流充电。
30 分钟不能达到 2.5V 每节以上，进入异常：绿灯灭，红灯闪烁。
```

结合参数表和硬件，当前实现应明确分成两段：

```text
1.0*N ~ 2.0*N：CH_REPAIR，硬件 REPAIR_OUTPUT 修复通路，约 100mA，不经过继电器。
2.0*N ~ 2.5*N：CH_Pre1，主充电预充，iPRE = 500mA。
```

注意：

```text
CH_REPAIR 不能调用 set_Curr_Duty(SET_CURR(iREPAIR))。
CH_REPAIR 不能闭合 JK1。
CH_REPAIR 只能打开 REPAIR_OUTPUT。
CH_Pre1 才使用 set_Curr_Duty(SET_CURR(iPRE))。
```

30 分钟超时要求：

```text
从低压充电开始计时。
30min 内不能达到 2.5*N 以上，进入异常。
异常 LED：红闪，绿灭。
```

### 4.4 3.24 大于 2.5*N V

规格：

```text
电池电压大于 2.5*N V：进入大电流 CC 充电，红灯灭，绿灯闪烁。
```

软件应满足：

```text
val.vout > vPRE_37V5：进入 CH_CCCV / CC 阶段。
vPRE_37V5 = 2.5V * N。
继电器闭合。
主 PWM 输出。
红灯灭，绿灯 1Hz 闪。
```

### 4.5 3.25 满电

规格：

```text
达到 4.20*N V 后逐渐减少充电电流。
电流减少到关断电流时，指示充满，完全切断充电。
```

软件应满足：

```text
满电电压：63.0V。
关断电流：500mA。
进入 CH_FULL 后 PWM=0，继电器断开，REPAIR_OUTPUT=0。
红灯灭，绿灯常亮。
保护动作时不得有输出电压和电流。
```

### 4.6 3.26 / 3.27 异常恢复

规格：

```text
温度异常：温度恢复后可自行充电。
电流异常 / 电压异常 / 通信异常：必须重新插拔电池后才能再次运行。
```

软件应满足：

```text
BMS_TEMP_ERR：关闭输出，红绿 1Hz 交替闪，温度恢复后允许自动重新握手/重新充电。
CH_UVP / CH_OVP / CH_OCP / BMS_ERR / CH_TimOut / CCCV_TimOut / HW_ERR：关闭输出，红闪绿灭，不能自动恢复，必须等电池拔出后回 CH_IDLE。
```

## 5. `usr_cfg.h` 充电电压/电流阈值依据

> 后续用户会把本文从 `<2026-07-05-当前交接>` 重命名为《程序修改计划》。重命名后，本节仍必须保留，用于说明 `usr_cfg.h` 中关键充电阈值的规格依据，避免后续改参数时失去来源。

### 5.1 电压阈值

```text
BAT_SERIES = 15
依据：63V battery pack，4.20V * 15 = 63.0V。
用途：所有按 N 串计算的电压阈值基准。

CELL_LOW_MV = 1000mV
vSTART = CELL_LOW_MV * BAT_SERIES = 15V
依据：3.22 低于 1*N V 关断输出、红灯闪烁。
用途：低压异常边界 / 插入后有效电池电压下限。

CELL_REPAIR_MV = 2000mV
vPRE_30V = CELL_REPAIR_MV * BAT_SERIES = 30V
依据：参数表 2.7 涓流电压 1.0~2.0±0.1*N V。
用途：REPAIR_OUTPUT 硬件修复通路结束、转主预充边界。
注意：该边界不能用于 PWM 主充电小电流；CH_REPAIR 不调用 SET_CURR(iREPAIR)。

CELL_PRE_MV = 2500mV
vPRE_37V5 = CELL_PRE_MV * BAT_SERIES = 37.5V
依据：3.23/3.24，30min 内达到 2.5*N V 以上；大于 2.5*N V 进入大电流 CC。
用途：预充结束、转 CC/CV 边界。

CELL_FULL_MV = 4200mV
SET_vMAX = 63000mV
依据：3.25，达到 4.20*N V 后进入 CV；参数表充满截止 63V±0.20V。
用途：满电/CV 目标电压上限。

CELL_RECHG_MV = 4000mV
vCH60 = CELL_RECHG_MV * BAT_SERIES = 60V
依据：参数表 2.5 滞后恢复充电电压：最高单节电压小于 4.0±0.05V。
用途：只能作为总压参考。
注意：严格对齐时应优先用 B1 最高单节 cell_max_mv < 4000mV 附近判断恢复，不能只用 val.vout < vCH60。

vDCOVP = 64500mV
依据：参数表最高输出电压 64.3±0.5V，可作为充电器自身输出过压保护参考。
用途：硬件输出过压/异常保护参考。
注意：不能替代 63V 满电截止判断。
```

### 5.2 电流阈值

```text
iREPAIR = 100mA
依据：参数表 2.7 涓流电流 100mA 以下；硬件 REPAIR_OUTPUT 自动限流约 100mA。
用途：修复通路目标说明/调试显示/必要时作为参考。
注意：不用于 set_Curr_Duty(SET_CURR(iREPAIR))。

iPRE = 500mA
依据：参数表 2.8 预充电流 500±200mA；3.23 低压区预充电流。
用途：CH_Pre1 主充电预充电流。

iMAX = 3000mA
依据：参数表额定输出电流 3±0.3A。
用途：CC 大电流充电额定电流上限。

iGED = 500mA
依据：参数表充满截止电流 500±200mA；3.25 电流减少到关断电流后显示充满并切断输出。
用途：满电截止电流、充电中拔电池小电流参考。

iOCP = 3500mA
依据：参数表过流保护 3.5±0.3A。
用途：过流保护动作阈值。

iOCP_OK = 3200mA
依据：过流保护恢复滞回设计值，低于 iOCP。
用途：防止过流判断在临界点抖动。
注意：参数表没有直接给出 3200mA，属于软件滞回工程值，后续如客户验收追问需说明。
```

### 5.3 时间阈值

```text
TIM_PRE = 30min
依据：参数表 2.7 涓流时间 30min±5%；参数表 2.8 预充时间 30min±5%；3.23 30min 内不能达到 2.5*N 以上则异常。
用途：低压修复/预充阶段超时保护。

TIM_CCCV = 480min
依据不足：参数表要求定时关断保护 = 容量 / 电流 * 60min * 1.25 + 30min。
用途：当前固定 CC/CV 超时上限。
注意：后续必须核对是否已按 A1 容量和当前充电电流动态计算；不能只依赖固定 TIM_CCCV。
```

### 5.4 后续修改原则

```text
1. 改 `usr_cfg.h` 任何充电阈值时，必须同时写明规格依据。
2. 电压阈值优先按 15 串、单节电压 * BAT_SERIES 推导。
3. 满电截止按 63V + 500mA，不使用 64.5V 代替。
4. 低压修复 CH_REPAIR 按 REPAIR_OUTPUT 硬件通路，不走主 PWM。
5. 满电恢复优先看最高单节电压，不只看总压。
6. 软件工程滞回值必须标注“规格未直接给出”。
```

## 6. 必须修改清单

### 6.1 CH_REPAIR 通路修正

```text
文件：YAT-60V3A-Uart-1-wire/App/ch.c

必须改：
1. 删除 CH_REPAIR 中的 set_Curr_Duty(SET_CURR(iREPAIR))。
2. CH_REPAIR 中确保主 PWM 输出关闭。
3. CH_REPAIR 中确保 JK1 继电器不闭合。
4. CH_REPAIR 中只打开 REPAIR_OUTPUT。
5. 离开 CH_REPAIR 时关闭 REPAIR_OUTPUT。
6. iREPAIR 只作为硬件修复电流说明/判断参考，不再用于 SET_CURR。
```

### 6.2 DUMMY_LOAD 5 秒窗口

```text
文件：YAT-60V3A-Uart-1-wire/App/ch.c

必须改：
1. 增加“负载突然断开”触发逻辑。
2. 触发时 DUMMY_LOAD = 1。
3. 启动 5 秒计时。
4. 5 秒后 DUMMY_LOAD = 0。
5. 正常充电、预充、修复、满电、待机时不得随意打开 DUMMY_LOAD。
6. 进入停机/异常时，除正在执行 5 秒假负载窗口外，DUMMY_LOAD 最终必须关闭。
```

### 6.3 低压/预充/CC 分段

```text
文件：YAT-60V3A-Uart-1-wire/App/ch.c

必须改/核对：
1. val.vout < vSTART：电压异常，红闪绿灭，关输出。
2. vSTART <= val.vout < vPRE_30V：CH_REPAIR，REPAIR_OUTPUT 硬件修复通路。
3. vPRE_30V <= val.vout < vPRE_37V5：CH_Pre1，iPRE=500mA。
4. val.vout > vPRE_37V5：CH_CCCV / CC，大电流充电。
5. 低压充电 30min 不能达到 2.5*N 以上，进入异常，红闪绿灭。
```

### 6.4 vCH60 恢复判断

```text
文件：YAT-60V3A-Uart-1-wire/App/ch.c / uart_1_wire.c / uart_1_wire.h

必须改/核对：
参数表要求“最高单节电压小于 4.0±0.05V”后恢复充电。
不能只用 val.vout < vCH60 判断。
应优先使用 B1 解析出的最高单节电压 cell_max_mv < 4000mV 附近作为恢复依据。
```

### 6.5 温度按电芯型号区分

```text
文件：YAT-60V3A-Uart-1-wire/App/uart_1_wire.c / uart_1_wire.h / ch.c

必须改/核对：
1. 识别电芯型号或电池包配置。
2. 18650：保护 -2~50℃，恢复 0~45℃。
3. 21700：保护 -2~57℃，恢复 0~50℃。
4. 不能只看 B4 温度异常位就算完成对齐。
```

### 6.6 LED 状态

```text
文件：YAT-60V3A-Uart-1-wire/App/ch.c

必须逐状态核对：
1. 待机：红常亮，绿灭。
2. CH_REPAIR / CH_Pre1 / CH_CCCV：红灭，绿 1Hz 闪。
3. 电压异常：红 1Hz 闪，绿灭。
4. 温度异常：红绿 1Hz 交替闪。
5. 满电：红灭，绿常亮。
6. 电流/通信异常：红闪绿灭，且必须拔插恢复。
```

### 6.7 定时关断保护

## 7. 当前不要再沿用的旧说法

以下旧文档说法已作废：

```text
1. “CH_REPAIR 已补无电流检查，val.curr < 30mA 连续 3 秒进入 HW_ERR。”
   作废原因：CH_REPAIR 走 REPAIR_OUTPUT 独立硬件限流通路，不是主电流检测/PWM 通路。

2. “CH_REPAIR 修复小电流输出需要 set_Curr_Duty(SET_CURR(iREPAIR))。”
   作废原因：REPAIR_OUTPUT 打开后硬件自动限流到约 100mA。

3. “vPRE_30V 没有依据，应从充电逻辑删除。”
   作废原因：vPRE_30V 对应 2.0V*N，是涓流/硬件修复到主预充的边界；但不能用于 PWM 预充。

4. “DUMMY_LOAD 可作为状态固定动作。”
   作废原因：DUMMY_LOAD 只在负载突然断开时打开 5 秒。

5. “vCH60 只看总电压恢复。”
   作废原因：参数表写的是最高单节电压小于 4.0±0.05V。
```
