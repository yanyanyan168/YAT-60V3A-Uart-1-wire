## 已完成逻辑核对

### CH_Check

不做无电流检查。

原因：该状态输出关闭，只负责：

```text
1. BATT_DIVIDER_EN = 1
2. 采样电池电压
3. 检查 BMS 状态
4. 决定进入 CH_REPAIR / CH_Pre1 / CH_CCCV
```

### CH_REPAIR

已补无电流检查。

```text
修复小电流输出已开启
通信正常
充电开始超过 2 秒
val.vout > vSTART
val.curr < 30mA 连续 3 秒
=> HW_ERR，日志：有压无流
```

### CH_Pre1

已做无电流检查。

```text
按 iPRE 判断，避免协议目标电流偏小导致漏判
val.curr < 100mA 连续 3 秒
=> HW_ERR，日志：有压无流
```

### CH_CCCV

已做无电流检查。

```text
按协议目标电流判断
val.curr < 100mA 连续 3 秒
=> HW_ERR，日志：有压无流
```

接近目标电压 500mV 内跳过，避免误判满电末端。
