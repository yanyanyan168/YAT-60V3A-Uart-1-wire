## 4. 最新硬件事实

### 4.1 REPAIR_OUTPUT / CH_REPAIR

```text
CH_REPAIR 走独立硬件修复通路。
REPAIR_OUTPUT 打开后，硬件自动限流到约 100mA。
该通路不经过 JK1 继电器。
CH_REPAIR 不需要打开继电器。
CH_REPAIR 不需要 set_Curr_Duty(SET_CURR(iREPAIR))。
```

因此旧说法作废：

```text
CH_REPAIR 不是 PWM 主充电小电流。
CH_REPAIR 不应使用 set_Curr_Duty(SET_CURR(iREPAIR))。
CH_REPAIR 不应按 val.curr < 30mA 连续 3 秒做有压无流故障，除非后续确认修复支路电流确实经过同一电流采样。
```

### 4.2 DUMMY_LOAD

```text
DUMMY_LOAD 默认关闭。
只在负载突然断开时打开。
打开后保持 5 秒。
5 秒后自动关闭。
```

DUMMY_LOAD 不是 CH_REPAIR、CH_Pre1、CH_CCCV、CH_FULL 的常规固定动作。

## 5. 关键参数依据

```text
BAT_SERIES = 15
vSTART = 1.0V * N = 15V
vPRE_30V = 2.0V * N = 30V
vPRE_37V5 = 2.5V * N = 37.5V
SET_vMAX = 4.20V * N = 63V
iPRE = 500mA
iGED = 500mA
iOCP = 3500mA
TIM_PRE = 30min
```

解释：

```text
vSTART：3.22 低于 1*N V 异常，有依据。
vPRE_30V：参数表涓流/硬件修复 1.0~2.0*N 边界，有依据；但不能用于 PWM 主充电电流。
vPRE_37V5：3.23/3.24 预充转 CC 的 2.5*N 边界，有依据。
vCH60：4.0V*N 有恢复电压来源，但参数表要求最高单节 <4.0±0.05V，不能只看总压。
```

## 6. 必须修改记忆

```text
1. CH_REPAIR：只打开 REPAIR_OUTPUT；不闭合 JK1；不调用 SET_CURR(iREPAIR)；主 PWM 保持关闭。
2. CH_Pre1：主充电预充，继电器闭合，使用 iPRE=500mA。
3. CH_CCCV：主充电 CC/CV，按 63V 和截止电流 500mA 满电。
4. DUMMY_LOAD：负载突然断开时打开 5 秒，到时关闭。
5. 满电后恢复：优先按 B1 最高单节 cell_max_mv <4000mV 附近，不应只用 val.vout < vCH60。
6. 温度保护/恢复：必须区分 18650 / 21700。
7. 温度异常可自动恢复；电压/电流/通信异常必须拔插恢复。
8. LED 必须严格对齐规格：待机红常亮、充电绿闪、电压异常红闪、温度异常红绿交替、满电绿常亮。
```
