## 修改范围

```text

```

本文件保持：GBK/CP936，无 BOM，CRLF。

## 本轮主要目标

1. 充电流程扁平化。
2. 不再把 `ch_state` 相关逻辑散落在多个 helper 或多个 `switch` 中。
3. `BATT_DIVIDER_EN` 逻辑更直观。
4. 完善有压无流异常。
5. 保持小 MCU 工程风格：少抽象、少宏、状态 case 内直接可读。

## 状态机整理

当前只保留一个主状态机：

```c
switch(ch_state)
```

各状态 case 内直接处理：

```text
1. 一线通信阶段设置
2. BATT_DIVIDER_EN 控制
3. ADC 采样
4. 保护检查
5. 拔电池判断
6. 有压无流判断
7. 当前状态业务跳转
```

## BATT_DIVIDER_EN 逻辑

### 待机到 CCCV

以下状态保持 `BATT_DIVIDER_EN = 1`：

```text
CH_IDLE
BMS_HANDSHAKE
CH_Check
CH_REPAIR
CH_Pre1
CH_CCCV
```

目的：保证当前 ADC 电压换算有效。

### 满电/异常

以下状态输出关闭，分压默认关闭，每 1 秒短开一次：

```text
CH_FULL
BMS_TEMP_ERR
BMS_ERR
CH_OTP
CH_TimOut
CCCV_TimOut
CH_UVP
CH_OVP
CH_OCP
NTC_ERR
HW_ERR
```

短开规则：

```text
每 1 秒打开一次
打开 20ms 后 ADC 有效
最多打开 100ms
```

目的：降低分压漏电和倒灌风险。

## 拔电池逻辑

### CH_Pre1 / CH_CCCV

继电器闭合时不能直接用 `val.vout` 判拔电池，因为可能是充电器输出电压。

当前逻辑：

```text
val.curr < iGED 且 u1w_info.no_rx_10ms >= 100U
    -> 疑似充电中拔电池
    -> ch_output_all_off()
    -> BATT_DIVIDER_EN = 1
    -> 20ms 后用当前 ADC 换算的 val.vout 判断
```

判断结果：

```text
val.vout < vRESET -> CH_IDLE，日志：拔电池
否则 -> BMS_ERR，日志：拔出异常
```

### CH_FULL / 异常状态

只在短开分压并且 ADC 有效时判断：

```text
val.vout < vRESET 连续 2 次有效采样 -> CH_IDLE
```

## 有压无流逻辑

保留函数：

```c
ch_no_current_fault_check_10ms(target_voltage_mv, target_current_ma, full_margin_en)
```

该函数不再自己判断 `ch_state`，只由对应状态 case 调用。

### 不检查

```text
CH_Check 不检查无电流
```

原因：`CH_Check` 输出关闭，只负责判断电压和 BMS 状态。

### 检查状态

```text
CH_REPAIR
CH_Pre1
CH_CCCV
```

### 门限

```text
CH_REPAIR：val.curr < 30mA 连续 3 秒 -> HW_ERR
CH_Pre1 / CH_CCCV：val.curr < 100mA 连续 3 秒 -> HW_ERR
```

### CCCV 防误判

`CH_CCCV` 接近目标电压 500mV 内，不判有压无流，避免满电末端误报。
